# Intellihome app store for umbrelOS

**English** · [Čeština](#čeština)

Community app store for [umbrelOS](https://umbrel.com) with **IamHome Agent**: monitoring of your Umbrel server and its apps, e-mail alerts, a morning report, a dashboard and an AI agent that can check and manage the server for you.

Runs on Umbrel Home and on Raspberry Pi 5 (amd64 and arm64). **Requires umbrelOS 2.0 or newer**: the app reads the server state through the Umbrel MCP server, which older versions (1.x) do not have.

## Add the store to Umbrel
1. Open **App Store** in umbrelOS.
2. Click **⋯** in the top right corner → **Community App Stores**.
3. Paste `https://github.com/richiinfoset/intellihome-app-store` and click **Add**.
4. Open the **Intellihome** store and install **IamHome Agent**.

After installation the app guides you through the first setup. Updates appear in umbrelOS like for any other app.

## Čeština

Komunitní obchod pro [umbrelOS](https://umbrel.com) s aplikací **IamHome Agent**: hlídání Umbrel serveru a jeho aplikací, upozornění e-mailem, ranní report, přehled s grafy a AI agent, který za tebe server zkontroluje a spravuje.

Běží na Umbrel Home i na Raspberry Pi 5 (amd64 i arm64). **Vyžaduje umbrelOS 2.0 nebo novější**: stav serveru aplikace čte přes Umbrel MCP server, který starší verze (1.x) nemají.

## Přidání obchodu do Umbrelu
1. V umbrelOS otevři **App Store**.
2. Vpravo nahoře klikni na **⋯** → **Community App Stores**.
3. Vlož `https://github.com/richiinfoset/intellihome-app-store` a klikni na **Add**.
4. Otevři obchod **Intellihome** a nainstaluj **IamHome Agent**.

Po instalaci tě aplikace provede prvním nastavením. Aktualizace se v umbrelOS ukazují jako u ostatních aplikací.
